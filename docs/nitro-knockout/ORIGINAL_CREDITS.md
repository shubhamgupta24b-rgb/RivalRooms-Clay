# Credits

## Original content

All kart models, arena geometry, interface art, visual effects, and synthesized audio were created procedurally for Nitro Knockout. No external art, models, textures, or audio files are used.

## Open-source libraries

- **Three.js** — MIT license. WebGL rendering.
- **Rapier** — Apache-2.0 license. WebAssembly rigid-body physics through `@dimforge/rapier3d-compat`.
- **React** — MIT license. Application shell.
- **Vite** — MIT license. Development and production build tooling.

Nitro Knockout is an original implementation inspired by the supplied kart-combat mechanics analysis; it does not contain assets or source code from Smash Karts.
